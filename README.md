# 波動實驗室 v2.0.0

可直接開啟的繁體中文互動波動教材。此版本已完成第 01～07 頁的互動教材。

## 開始使用

解壓縮後，使用較新的 Chrome、Edge、Firefox 或 Safari 開啟 `index.html`。互動模型不需網路，不需安裝 Node.js，不需 API 金鑰或帳號。

建議用電腦或平板投影教學。手機也可操作；地震波的四張圖會改為垂直排列。水波等二維模型在窄螢幕可左右滑動查看；三維模型會適應觀察窗，觸控時單指拖曳旋轉，或用視角按鈕操作。

## 放到 GitHub Pages

1. 在 GitHub 建立一個新 repository，例如 `wave-lab`。若使用 GitHub Free，可建立 public repository。
2. 用 **Add file → Upload files**，上傳「解壓後的內容」，包含 `index.html`、13 個 JavaScript 檔案、`styles.css`、`README.md` 與 `assets` 資料夾，並提交到 `main`。讓 `index.html` 位於 repository 最外層；不要只上傳 ZIP，也不要在它外面再套一層資料夾。
3. 開啟 **Settings → Pages**。Source 選 **Deploy from a branch**，Branch 選 **main**，資料夾選 **/ (root)**，按 Save。
4. 部署完成後，網址一般為 `https://你的帳號.github.io/wave-lab/`；實際網址以 Pages 顯示的結果為準。第一次發布可能需要等候數分鐘。

`.nojekyll` 已包含在壓縮檔中；它可避免 Jekyll 額外處理，若手動拖曳時沒有上傳這個隱藏檔，本專案的普通 HTML/JS 仍可使用。

更新時，將修改後的同名檔案提交到同一個 repository，即會依上述 Pages 設定重新發布。

## 教學與科學近似

- 水中質點的圓形軌跡採小振幅深水線性近似；真實水波可有 Stokes 漂移。有限水深使用 Airy 波軌道，但比較時固定動畫節奏，不用來比較真實水波的色散與速度。
- 水面斜視會把空間中的圓投影成橢圓。判斷圓形與橢圓形軌道時，請回到水中剖面。
- 空氣中的聲波為縱波。質點位移與壓力變化的相位不同，本模型用位移的空間導數推算壓力與疏密背景。
- 電磁波畫的是「場向量與場強」，其虛線不是物質質點軌道。真空平面波 E 與 B 同相位、互相垂直，且各自正規化後繪製。
- 地震波屬定性展示，S 波圖採 SV 偏振；Rayleigh 展示近地表逆行橢圓，未求解完整分層彈性場。實際運動、速度與旋向會受介質與深度影響。
- 重力波的起伏網格高度、凹陷與環形波紋是視覺類比，未求解廣義相對論方程。重力波的實際距離伸縮另在「距離伸縮」模式展示；未計算三維輻射角分布。位移與應變大幅放大，未模擬雙星合併。
- 回聲採一維、無風與完全反射模型；船題用 340 m/s，蝙蝠題依講義用 310 m/s。
- 聲強平方反比只適用於自由場、各向均勻的理想點聲源。人的響度知覺還受頻率與聽覺系統影響。
- 音色合成採穩定整數倍泛音，未模擬真實樂器的起音、衰減、噪聲與共鳴峰。音高通常由基頻或整體週期性主導，不必等於最大的頻譜峰。

各模型的公式與更多限制，請見實驗內的「給老師：模型假設與延伸說明」。本網站不提供定量真實物理預測。

### 重要模型界線

- 空氣固定 20°C，理想氣體近似聲速約 343 m/s；抽氣降低訊號強度，並非讓聲速等比例下降。真空不傳聲，顯示「無聲速」，不以 0 m/s 代替。
- 水聲速採 UNESCO / Chen–Millero 純水項在 0–20°C、近表面壓力的近似；20°C 約 1,482 m/s。冰中縱向聲速採代表值約 3,800 m/s，不含晶向或溫度依賴。凝固中不指定混合介質的單一速率。
- 可見光以 c/n 近似，n空氣＝1.00027、n水＝1.333、n冰＝1.31。1 m 的光行時間為數奈秒，因此不可能在與聲音相同時間尺度的動畫中緩慢前進；用瞬間到達的偵測器及數值呈現。光路虛線是輔助線，並非真空中可從側面看到的懸空光束。
- 假設鬧鐘、雷射與偵測器在各介質皆可正常運作；忽略容器、支架和電線傳聲，及凝固膨脹引起的壓力變化。傳播慢動作為 1 動畫秒＝1 毫秒；抽氣、降溫、凝固的操作時間另為示意。此實驗不播放聲音。
- 固定端反射波必須與入射波等頻率、等振幅並在牆面相消；從入射前緣抵達牆面後才產生反射波。不同頻率／振幅的疊加放在「兩個獨立波源」模式，避免誤把靜止牆面反射當成變頻來源。
- 反射只計右牆的一次反射，不模擬左端再次反射或雙端共振的振幅累積。穩定駐波才標示波節；等頻等振幅的獨立反向波也可形成純駐波，改變相位會平移波節。
- 純駐波的時間平均淨傳能為零，組成的兩個行進波仍各自向相反方向傳能。波包中所有質點的水平速度均為零，紅箭頭為解析垂直速度；長度有上限以保持可讀。

### 03 週期波的性質

- 「讀懂一張波形」同步標示波峰、波谷、平衡點、振幅與波長，可調振幅、波長與頻率。
- 「x–y 與 y–t 圖連動」由同一波函數同步繪製；可移動固定追蹤點、切換左右傳播，分別在空間軸量 λ、時間軸量 T。
- 將講義的「四個振幅」精確表述為平衡→峰→平衡→谷→平衡的鉛直變化量合計 4A，避免和波長、波形弧長混淆。

### 04 波速與頻率、波長、週期

- 同一介質：波速固定，調整波源頻率時即時計算 T 與 λ，呈現 f 與 λ 的反向關係。空氣、水、鋼皆使用固定 0～12 m 數線與相同慢動作比例（1 動畫秒＝1 ms），追蹤波峰可直接比較實際前進距離與波速。
- 跨介質：介面兩側的 f、T 保持相同，v 與 λ 同向改變；可選空氣、水、鋼並交換左右。
- 公式計算器：自由設定 v、f，同步得到 λ=v/f 與 T=1/f；固定 0～24 m 空間尺上的波形會依設定持續向右傳播。
- 跨介質圖會在左右半窗內使用共同視覺比例以保持可讀；同介質比較與公式計算器則使用固定實際長度尺。真實介面反射、吸收及阻抗未納入。
